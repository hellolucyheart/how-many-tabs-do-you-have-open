A Python program that counts one honest browser session — 137 open tabs, grouped by the life behind them — and writes the count, digits only, to `/output/entry.txt` for make.fun's "How Many Tabs Do You Have Open?" bounty. The number is derived, not hard-coded: the program lists every tab (read-later articles, queued videos, docs left open mid-debug, work boards, abandoned carts, a 214-message group chat, and a Wikipedia rabbit hole that ends at the dancing plague of 1518) and counts them. It runs offline, reads nothing from the network, and writes the same digits on every run.

## Run it

```sh
python3 main.py
```
